# Informe de implementación: nuevo requerimiento de género

## Resumen

Se implementó la nueva funcionalidad para determinar si hay más estudiantes hombres, más mujeres o la misma cantidad. El cambio respetó la arquitectura MVC del proyecto y la estructura de clases existentes.

## Archivos modificados

- `src/models/Cl_mEstudiante.ts`
- `src/models/Cl_mSalon.ts`
- `src/controllers/Cl_cSalon.ts`
- `src/controllers/Cl_cEstudiante.ts`
- `src/interfaces/I_vSalon.ts`
- `src/interfaces/I_vEstudiante.ts`
- `src/views/Cl_vSalon.ts`
- `src/views/Cl_vEstudiante.ts`
- `index.html`

## Cambios realizados

### Modelo

- `Cl_mEstudiante`:
  - Se agregó el atributo `sexo` al modelo del estudiante.
  - El constructor ahora inicializa `nombre`, `edad` y `sexo`.
- `Cl_mSalon`:
  - Se añadieron métodos `cantidadHombres()` y `cantidadMujeres()`.
  - Se agregó el método `comparacionGenero()` que devuelve:
    - `hombres` cuando hay más hombres,
    - `mujeres` cuando hay más mujeres,
    - `por igual` cuando las cantidades coinciden.

### Controlador

- `Cl_cSalon`:
  - Los datos iniciales incluyeron el sexo de cada estudiante.
  - Se actualizó la llamada a `mostrarEstudiantes()` para enviar `generoComparacion`.
  - Se mantuvo la lógica MVC, dejando la responsabilidad de cálculo en el modelo y la presentación en la vista.
- `Cl_cEstudiante`:
  - Se actualizó la creación de la instancia `Cl_mEstudiante` para incluir `sexo`.

### Vistas e interfaces

- `I_vSalon`:
  - Se extendió la interfaz para aceptar `generoComparacion` en el método `mostrarEstudiantes()`.
- `I_vEstudiante`:
  - Se agregó `get sexo(): string` al contrato de la vista de estudiante.
- `Cl_vSalon`:
  - Se agregó la columna `Sexo` en la tabla de estudiantes.
  - Se añadió la etiqueta de salida `Hay más: <...>` para mostrar el resultado de la comparación de género.
- `Cl_vEstudiante`:
  - Se agregó un campo `select` para elegir el sexo del estudiante.
  - Se expuso el valor `sexo` para que el controlador pueda crear el estudiante correctamente.

### HTML

- Se agregó el campo `Sexo` al formulario de entrada del estudiante.
- Se agregó la columna `Sexo` en la tabla de estudiantes.
- Se agregó una seccion en la interfaz principal para mostrar el resultado `Hay más: hombres/mujeres/por igual`.

## Resultado

La aplicación ahora puede procesar estudiantes con sexo y reportar correctamente si hay:

- más `hombres`,
- más `mujeres`, o
- `por igual`.

El cambio se realizó manteniendo la separación de responsabilidades del patrón MVC.
